המערכת

מערכת הקורס משמשת את המשתתפים להקמת פרויקט, לעבודה על מסמך הדרישות (PRD) שלו ולמעקב אחרי ההתקדמות.

מה המערכת מקבלת מגוגל

פרטי זהות: שם, כתובת מייל ותמונה, לזיהוי המשתתף.

גישה לקבצים שהמערכת יוצרת (ההרשאה drive.file): המערכת יוצרת בדרייב של המשתתף את תיקיית הפרויקט ואת מסמכי הפרויקט, וניגשת אליהם בלבד. לשאר הקבצים בדרייב של המשתתף אין למערכת גישה.

היכן המידע נשמר ושל מי הוא

תיקיית הפרויקט וכל הקבצים בה נשמרים בדרייב של המשתתף ובבעלותו. בהקמת הפרויקט, המשתתף משתף את מנהלת הקורס בהרשאת קריאה, לצורך ליווי. המערכת אינה מעתיקה את תוכן הקבצים לשרת אחר ואינה שומרת אותו מחוץ לדרייב של המשתתף.

שיתוף

המידע אינו נמכר, אינו משמש לפרסום ואינו מועבר לגורם שלישי.

שימוש מוגבל

השימוש של המערכת במידע שמתקבל מממשקי גוגל עומד במדיניות נתוני המשתמש של שירותי ה-API של גוגל, כולל דרישות השימוש המוגבל.

מחיקה וביטול הרשאה

המשתתף יכול לבטל את ההרשאה בכל עת בהגדרות חשבון הגוגל שלו, ולמחוק את תיקיית הפרויקט מהדרייב שלו. לבקשות נוספות: levavir@gmail.com.

Privacy Policy

Last updated: November 6, 2026. Responsible party: Rili Levavi, aethos-ai.com.

The system

The course system lets participants set up a project, work on its requirements document (PRD) and track their progress.

What the system receives from Google

Basic identity: name, email address and profile picture, to identify the participant.

Access to files the system creates (drive.file scope): the system creates the project folder and project documents in the participant's Google Drive, and accesses only those files. It has no access to any other file in the participant's Drive.

Where data is stored and who owns it

The project folder and all its files are stored in the participant's own Google Drive and owned by the participant. When the project is created, the participant shares it with the course instructor as view-only, for mentoring. The system does not copy file contents to any other server and does not store them outside the participant's Drive.

Sharing

Data is not sold, not used for advertising and not transferred to third parties.

Limited Use

The system's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion and revoking access

Participants can revoke access at any time in their Google Account settings, and delete the project folder from their Drive. For any other request: levavir@gmail.com.
