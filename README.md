# product-sign-in

Sign-in page of the new student launcher, at https://product.aethos-ai.com.
The page shows the Google sign-in window and posts the identity token to the Apps Script app, to the address the app passed in the app parameter, within the allow list in config.js.
The previous version for students: https://project.aethos-ai.com (repository course-sign-in). Specification: spec-app, chapter 5.2.
